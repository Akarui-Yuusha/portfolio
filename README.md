# Portfolio — Akarui Yuusha

A simple single-page personal portfolio website built with **HTML, CSS, and JavaScript**
for CC107 Activity 4 (Application Development – Web Platforms).

## Sections

1. **Header / Navigation** — brand name + anchor links to each section.
2. **Hero / About Me** — profile photo, short introduction, and a brief bio.
3. **Projects** — three project cards with titles and descriptions.
4. **Footer / Contact** — email, GitHub link, and LinkedIn.

## Requirements met

- **HTML** — semantic tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`), the
  viewport meta tag, and `alt` text on the image.
- **CSS** — separate `style.css`, no inline styles, Flexbox layout, hover effects, and a
  `@media` query so the page is responsive on mobile.
- **JavaScript** — separate `script.js`, commented, with one working interactive feature:
  a **hamburger menu** that shows and hides the navigation on small screens.

## Files

```
index.html          The page with all four sections
style.css           All styling and the responsive rules
script.js           The hamburger menu feature
images/avatar.svg   Profile picture
```

## How to run

Open `index.html` in a web browser. No setup is needed.
